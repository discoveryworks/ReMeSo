# ReMeSo agent instructions

ReMeSo is a convention for repeatable agent archetypes. It does not require a skill or software package.

Use the project's root AGENTS.md pointer to find this instruction file and the actual agent-definition location. Paths are project-specific; `remeso/` and `agents/<agent-name>/` are conceptual examples, not relocation instructions. No universal loader is assumed.

Each archetype has three files:

- **REMIT.md:** responsibilities, expected work and what the agent ought to delegate. Its responsibility sections are “Things I’m primarily responsible for” and “Things I ought to be delegating”.
- **MEMORY.md:** a rewritable, palimpsesty cache of proximate context and recent learnings, which can change independently of the remit.
- **SOUL.md:** perspective and disposition, including longer-lived learnings or epiphanies that shape judgment.

These distinctions organize existing instructions; they do not themselves grant authority or change project policy.
